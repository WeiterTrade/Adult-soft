# Биографии для офлайн-библиотеки

Папка `.bio` лежит в корне папки с фильмами (рядом с папками студий). В ней — по одному файлу на человека:

```
XXX/
├── .bio/
│   ├── Phoenix_Marie.txt
│   └── Cory_Chase.txt
├── Остальные Студии/...
```

* Имя файла — как фото в `.actors`: `Имя_Фамилия.txt` (пробелы → `_`).
* Внутри — биография **ровно в том виде, как её присылает чат**: «Биография», абзацы,
  «Краткая справка» и пункты `* Поле: значение`. Ничего переделывать не нужно.
* Кодировка — UTF-8 (Блокнот по умолчанию сохраняет так).

Распознаются поля «Настоящее имя», «Псевдонимы», «Дата рождения», «Дата смерти», «Место рождения»;
остальные пункты (рост, годы активности, жанры, достижения…) показываются списком на странице актрисы.

## Быстро добавить из чата (Windows)

1. Скопируйте биографию из чата (Ctrl+C).
2. Запустите `add-bio.bat`. В первый раз выберите папку с фильмами — скрипт создаст в ней `.bio` и запомнит.
3. Введите имя латиницей (`Phoenix Marie`) — файл сохранится.
4. Копируйте следующую биографию и жмите Enter — и так подряд.

После добавления: в приложении **Настройки → Офлайн-библиотека → «Сканировать папки»**.
